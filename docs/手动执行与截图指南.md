# 执行指南（全部在 Databricks 上完成）

整个项目在 Databricks 的 notebook 里运行。学员只需要一个浏览器，不需要在自己电脑上安装 Python、MySQL 或 Databricks CLI。

每一步对应仓库里的一个分支（`step-00` … `step-10`）和一个 notebook（`notebooks/stepNN_*.py`）。切到哪个分支，代码就是那一步的状态，按顺序运行对应的 notebook 即可。

---

## 一、准备（只做一次）

### 1.1 需要的账号

| 账号 | 用途 | 获取方式 |
|---|---|---|
| Databricks | 运行全部代码、存放数据、部署网页 | 注册 Free Edition：https://www.databricks.com/learn/free-edition （已有账号直接登录：https://login.databricks.com ） |
| 智谱开放平台 | 默认模型 glm-4-flash（免费） | https://open.bigmodel.cn → 控制台「API Keys」创建 key |
| DeepSeek（可选） | 更强的模型，按量计费 | https://platform.deepseek.com → API keys |

不需要 HuggingFace 账号：BEAVER 数据已经做成公开的课程数据包，notebook 会自动下载。

### 1.2 把仓库克隆到 Databricks

1. 登录 Databricks，左侧点 **Workspace**，进入自己的用户目录（`/Users/<你的邮箱>`）。
2. 右上角 **Create → Git folder**，填写：
   - Git repository URL：`https://github.com/mushan-shine/text2sql-loop-engineering`
   - Git provider：GitHub（公开仓库不需要填 token）
3. 创建后进入这个文件夹，就能看到项目的全部代码。

### 1.3 切换到某一步

在 Git folder 页面顶部点分支名（默认 `main`），在下拉框里选择 `step-00`、`step-01` …… 切换后，代码就是那一步的状态。

- `data/`、`runs/`、`app/bundle/` 里的运行结果不受 git 管理，切换分支时会保留，前一步的产出可以给后一步用。
- `main` 是全部步骤完成后的最终代码。

### 1.4 运行 notebook 的通用操作

1. 打开 `notebooks/` 下对应的 notebook。
2. 右上角的计算资源选 **Serverless**（Free Edition 默认就是）。
3. 点顶部的 **Run all**，或从上到下逐格运行（Shift + Enter）。
4. 每个 notebook 的前三格固定是：安装依赖 → 重启 Python → 公共准备（`%run ./_setup`）。重启那一格会清掉之前的变量，属于正常现象。

### 1.5 截图注意（仓库和截图都会给学员看）

- 不要截到 API key：输入 key 的那一格运行后，输入框会自动清除，截图前确认；
- 你的邮箱、工作区地址（浏览器地址栏）、SQL warehouse 编号、App 地址建议打码；
- 文件命名建议：`step-<N>-<序号>-<内容>.png`。

## 三、进阶：在本地运行（可选）

想完整体验步骤 1 的“MySQL 与 Databricks 双引擎比对”，需要在本地安装 Python 3.11+、MySQL 8.0 和 Databricks CLI，申请 HuggingFace 上 BEAVER 的访问权限，然后按 README 用 `python scripts/phase0.py all` 运行。其余步骤的脚本在本地也可以运行，命令与 notebook 里的 `run_script(...)` 一一对应（例如 `run_script("phase1.py", "dev")` 对应 `python scripts/phase1.py dev`）。
